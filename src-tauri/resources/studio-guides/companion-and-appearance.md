## The companion

The companion is the bison in a corner of the screen, above other apps. It shows a count when something needs the user. A click (or Cmd/Ctrl+Shift+Space) opens a card with what needs them, what's running and what finished recently. Dragging moves it; it snaps to the nearest corner and stays there after a restart.

## When the bison doesn't move

The bison moves by default. It lies down breathing in a short loop. The setting is Settings › Appearance › **Bison moves**:

- **Always** (the default): it moves, whatever the computer's motion setting.
- **When the system allows**: it holds still when the computer is set to reduce motion. On Windows that's Settings › Accessibility › Visual effects › **Animation effects** off; on macOS, System Settings › Accessibility › Display › **Reduce motion** on.
- **Never**: it always holds still.

If the user says the bison doesn't move, check this setting first. If they want it still, tell them to pick **Never** (or **When the system allows**, to follow the computer).

## Other companion settings

All are in Settings › Appearance › Companion:

- **Nandi on the desktop**: turn off to have no bison at all; the shortcut then shows and hides the card.
- **Start with only the bison**: launch with just the companion, not the main window.
- **Notify me**: native notifications for new approvals and questions while the card is closed. Also in the companion's ⋯ menu.

Closing the main window leaves the companion running. **Open in Nandi** brings the window back, and **Quit Nandi** in the ⋯ menu quits.

## Appearance

Settings › Appearance also holds light, dark or system mode, the colour palette (which also changes the window icon), the language (right-to-left for Arabic) and the bison's name.
