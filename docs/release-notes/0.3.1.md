## Nandi 0.3.1

Download from https://vaultdb.ai (or below). Requires Docker.

Nandi 0.3.1 fixes browsing: agents' browsers open sites like Google again, a page's extra sites are asked for in one card, and your own Nandi browser no longer asks about every site. The full list is in [CHANGELOG.md](https://github.com/vaultdbai/nandi/blob/v0.3.1/CHANGELOG.md).

### Fixed

- **Agents' browsers open Google again.** A navigation no longer hangs for 60 seconds: the browser has its own way into Nandi's proxy, with no sign-in prompt to get stuck on.
- **One card for everything a page needs.** When an allowed page needs other sites (images, a consent page), one "Allow this site?" card names them all, and one yes covers them. Allow once now lasts the whole run.
- **Your own window is yours.** Open my Nandi browser goes through Nandi's proxy and records every connection, but only Nandi's policies block a site, and your browsing never widens an agent's allowed sites.

### Changed

- **The sitting bison is Nandi's icon,** in the app, the window for every colour theme, and the installers.

### Known issues

- **The installers aren't signed yet.** Windows shows "unknown publisher": click More info, then Run anyway. macOS: open it from System Settings › Privacy & Security › Open Anyway.
- **Google may say "Google hasn't verified this app"** when you connect Gmail. Click Advanced, then Go to Nandi.

### Installation

- **macOS**: download the `.dmg` and drag Nandi to Applications.
- **Windows**: `-setup.exe` (no admin rights needed) or `.msi` for IT deployment (`msiexec /i VaultDB-Nandi-windows-x64.msi /qn`).
- **Linux**: download the `.AppImage`, make it executable (`chmod +x`) and run it.

Existing users get an update notification once this release is published.
