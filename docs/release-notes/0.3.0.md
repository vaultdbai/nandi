## Nandi 0.3.0

Download from https://vaultdb.ai (or below). Requires Docker.

Nandi 0.3.0 reads every inbox you have, lets you approve from your phone, and keeps the keys agents use where they can't see them. The full list is in [CHANGELOG.md](https://github.com/vaultdbai/nandi/blob/v0.3.0/CHANGELOG.md).

### Headline changes

- **Every inbox you have, one you.** Connect all your Gmail and Outlook accounts, with their Drive or OneDrive and calendar. One morning brief across all of them, grouped by mailbox.
- **Your yes, from anywhere.** Pair your phone with a QR code and a PIN, then approve or decline from wherever you are. Sealed end to end through the relay. Anything that reaches outside an agent's sandbox stays on the computer.
- **The Lock box.** API keys and passwords that agents use but never see, bound to their sites, for the agents you allow, asked each time by default.
- **My Nandi browser.** Sign in once in a browser profile Nandi keeps for you; agents you allow use those sign-ins.
- **It gets better every week.** Suggested changes from what you corrected, each with its reasons. You say yes, and can undo.
- **`agent.md`** is the one file that makes an agent.

### Upgrading from 0.2.3

Accept the update, or install 0.3.0 over 0.2.3. On first start:

- Your connected mailbox moves to its new per-account names. You stay signed in, and no mail is read twice. Separate calendar and files connections move under the matching account.
- Your agents' `skill.md` files become `agent.md`, in one commit: "Upgrade agents to agent.md".
- Packs you installed are renamed the same way and keep working.

### Known issues

- **The installers aren't signed yet.** Windows shows "unknown publisher": click More info, then Run anyway. macOS blocks the first open: open it from System Settings › Privacy & Security › Open Anyway. Signed installers come in 0.3.1.
- **Google may say "Google hasn't verified this app"** when you connect Gmail. Click Advanced, then Go to Nandi. Nandi reads mail read-only, on your computer.
- **Locked keys** use Windows Hello on Windows; on macOS and Linux they ask each time instead.
- **Your phone** pairs from `vaultdb.ai/pair` (iPhone needs iOS 17 or later). Face ID is not used yet: you type the PIN.
- **Gemini CLI** can't run in the container yet, and **Codex** needs an OpenAI API key.

### Installation

- **macOS**: download the `.dmg` and drag Nandi to Applications.
- **Windows**: `-setup.exe` (no admin rights needed) or `.msi` for IT deployment (`msiexec /i VaultDB-Nandi-windows-x64.msi /qn`).
- **Linux**: download the `.AppImage`, make it executable (`chmod +x`) and run it.

Existing users get an update notification once this release is published.
